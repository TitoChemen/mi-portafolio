# 🚀 Sobre el proyecto

Este proyecto consiste en el desarrollo de un **portafolio web personal utilizando React**, donde se presentan diferentes secciones relacionadas con mi perfil, proyectos, noticias y contenido personal.

El objetivo principal es aplicar los conocimientos adquiridos durante la asignatura, utilizando componentes reutilizables, diseño responsive, pruebas unitarias y herramientas de control de versiones.

# ⚙️ Instalación y ejecución

## 1. Clonar el repositorio

```bash
git clone https://github.com/pedrohacker20/pedrohacker20.github.io.git
cd pedrohacker20.github.io
```

## 2. Instalar las dependencias

Asegúrate de tener **Node.js** instalado y ejecuta:

```bash
npm install
```

## 3. Ejecutar el proyecto

Para iniciar el proyecto en modo desarrollo:

```bash
npm start
```

La aplicación estará disponible en:

```text
http://localhost:3000
```

# 🧪 Pruebas unitarias
